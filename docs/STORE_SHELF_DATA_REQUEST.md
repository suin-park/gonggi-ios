# 제공해 주실 자료 (한 번에, 같은 냉장고 재촬영 없이)

빌드 97을 설치하고, 아래를 **한 번씩만** 하면 됩니다. 이후 수정 전후 비교는 이 자료를 반복 재생해서 합니다.

## A. 기록 1회 (정답표 + 진단 ZIP + 화면 캡처)

1. 촬영 **전에** 종이나 메모에 정답표를 적습니다(5분).
   - 냉장고 안 **서로 다른 제품이 몇 종류**인지, 각 제품의 **포장에 적힌 이름 그대로**, 어느 칸(아래서 몇 번째, 왼쪽/가운데/오른쪽)에 몇 개 있는지.
   - 아래 사례가 **각각 하나 이상** 포함되어 있는지 표시합니다.
     - 같은 제품이 두 곳 이상에 놓인 것
     - 같은 브랜드의 맛/용량이 다른 제품이 나란히 있는 것
     - 큰 포장 하나, 단색(무늬 없는) 포장 하나
     - 한글 이름 제품, 영문 이름 제품, 한영 혼합 제품
     - 선반, 문틀, 조명이 화면에 보이는 구도
2. 앱에서 평소처럼 「매대 기록하기」를 1회 진행합니다(60~90초, 천천히, 제품이 화면 높이의 1/6 이상으로 보이게).
3. 검토 화면에서 **아무것도 수정하지 않습니다.**
4. 검토 화면을 **스크롤하면서 캡처**(맨 위 진단 한 줄 포함, 2~4장).
5. 「진단 자료 내보내기」를 눌러 ZIP을 만들고, 공유 시트에서 「파일에 저장」(iCloud Drive) 또는 메일/AirDrop으로 PC로 옮깁니다.
6. 그 다음에 필요하면 이름을 수정하고 저장해도 됩니다(이름 수정 후 다시 내보내면 수정된 이름이 `reviewedNames`로 따로 기록됩니다).

## B. 제품 찾기 1회 (등록 때와 다른 시점의 촬영)

A의 기록을 저장한 뒤(게시 불필요: 관리자 화면의 「이 기기의 기록으로 찾아보기」 또는 게시 후 고객 화면):

1. 등록된 제품 5개를 하나씩 약 10초씩 화면 가운데에 비춥니다(제품마다 위치를 바꿔서, 가능하면 등록 때와 다른 각도).
2. 등록하지 **않은** 제품 2개를 비춥니다(미등록 확인).
3. 맛/용량만 다른 제품(변종)이 있으면 하나 비춥니다.
4. 제품을 겨냥하지 않고 매대 전체를 천천히 훑습니다(오인식이 안내로 이어지는지 확인).
5. 어떤 제품이 확정되어 안내가 시작되는 순간까지 걸린 체감 시간과, 공간이 맞춰졌는지(「공간 맞춤 ✓」)를 메모합니다.
6. 제품 찾기 화면 아래 「진단 자료 내보내기」로 ZIP을 만들어 A와 같은 방법으로 옮깁니다.

## C. 전달

- ZIP 2개(기록, 검색), 정답표(사진 또는 텍스트), 검토 화면 캡처를 `C:\Users\emili\Downloads` 아래 한 폴더에 넣고 경로만 알려 주세요.
- ZIP에는 매장 사진이 들어갑니다. 얼굴이나 개인정보가 찍히지 않게 해 주세요.

## D. 아이폰에서 직접 확인해야 하는 것 (자료로 대체할 수 없음)

- 기록 흐름이 끝까지 되는지, 내보내기 버튼으로 ZIP이 만들어지는지.
- 검색에서 확정까지 체감 시간, 공간 복원 후 안내가 시작되는 체감 시간, 미등록 제품을 비췄을 때 안내가 시작되지 않는지.
- 두 아이폰 사이 게시본 동기화와 공간 복원.
