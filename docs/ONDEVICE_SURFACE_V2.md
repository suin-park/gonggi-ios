# 실시간 공간 생성 V2 (온디바이스 표면 지도 + 원본 영상 투영)

기록하기 › 실험 › **실시간 공간 생성 V2**. 기존 "실시간 공간 생성"(3.0(18)/(19)의 가우시안 경로)은 비교용으로 그대로 둔다.

## 무엇인가

iPhone 14 Plus(LiDAR 없음)에서 **서버·장면별 학습·사전학습 모델 없이** 촬영하는 동안 저장 가능한 3D 공간을 만든다.
형상은 검증 가능한 영구 표면 패치(사각형)로, 외관은 원본 키프레임을 표면에 픽셀 단위로 투영해 읽는다.

- 사용하는 것: ARKit 추적(포즈·K), 영상 대응(평면 스윕 ZNCC), 삼각측량, RANSAC, 누적 통계, 역분산 가중 융합.
- 사용하지 않는 것: 서버, 장면별 SGD/Adam/역전파, Depth Anything·VGGT·SHARP 등 사전학습 모델 추론(V2 기본 경로에서 호출하지 않는다. 비교 경로의 Depth Anything은 앱에 남아 있다).
- Apple 내부(ARKit 추적·ISP)가 무학습이라고는 주장하지 않는다.
- 합성 CPU 검증은 iPhone 속도·깊이 복원 성공·실사 화질을 증명하지 않는다.

## 데이터 흐름

```
ARSession(하나) → ARFrame에서 한 번에 복사: RGB(960폭) · 포즈 · K · 시각(host/uptime) · 추적 상태 · 노출(duration/offset) · 방향
  → SV2Input  ───────────────┬─→ (연구 기록 옵션) SV2ReplayRecorder → .kmoreplay
                              ↓
  SV2Pipeline.process (한 큐, ARKit 비의존: 실시간·재생·테스트가 같은 경로)
    1. 변환: 960폭 RGBA(텍스처) + 320폭 RGB/gray(깊이)
    2. 참조 선택 SV2Depth.selectRefs: 횡방향 기선 ≥ 3.5cm, 겹침(회전 ≤ 28°), 가능하면 반대쪽 참조
    3. 깊이 SV2Depth.estimate: 평면 스윕 ZNCC(RTStereo, 지도 prior 없음) + σZ + 역방향 일치(가장 큰 기선의 참조에서 거꾸로 추정해 대조)
    4. 표본 SV2PatchBuilder: 5×5 창 평면 맞춤 법선, 경계/불확실/먼 표본 거부, 경계를 가로지르는 보간·연결 없음
    5. 저텍스처: 검증된 평면(SV2PlaneModel, RANSAC) 안에서만 채움(독립 증거 아님), 이웃 깊이가 어긋나면 채우지 않음
    6. 융합 SV2SurfaceMap.integrate: 패치당 한 번 집계 → 칼만(역분산) 갱신, 독립 증거 계산, 상태 전이, 모순 검증, 자유 공간 위반
    7. 키프레임 저장소(JPEG q0.82), 패치-키프레임 링크(표면-관측 연결)
  → SV2Scene 스냅샷 → SV2Renderer(Metal)
       source 선택: 보이는 패치의 링크로 덮이는 면적이 큰 키프레임 4장(이력 가중)
       source별 깊이(가림 캐시) 패스 → 본 패스에서 화소마다 source 투영·가림·각도·해상도 가중·색 일치 검사
  → 종료·저장: .kmospace + 호환 PLY/.state + .meta.json + .summary.txt (+ .kmoreplay) → 저장 파일을 다시 읽어 화면에 표시
```

## 표면 지도(영구)

- 패치: stable ID, 상태(임시/후보/안정), 중심·법선·반 크기, 법선 방향 불확실성 σ, 독립 증거 목록, geometryRevision, 링크.
- **독립 증거**: 카메라 위치·시선이 충분히 다르고(≥ 4cm 또는 ≥ 3.5°) 깊이 추정에 쓴 참조 키프레임이 겹치지 않을 때만 센다. 같은 위치의 반복, 같은 참조를 재사용한 결과는 낮은 가중(0.25)으로만 쓰고 독립 증거로 세지 않는다.
- **갱신**: 같은 키프레임의 표본은 패치당 하나로 집계(유효 표본 수 ≤ 2). 위치는 법선 방향 역분산 가중 칼만 갱신. 약한 표본은 후보 이상 패치의 위치·법선·대체 색을 바꾸지 못한다.
- **승격**: 후보 = 독립 증거 ≥ 2, 잔차 ≤ 1.5σ. 안정 = 독립 증거 ≥ 4, 기선 ≥ 8cm, 시선 각도 ≥ 5°, 잔차 ≤ 0.8σ, σ ≤ 1cm + 1.2%·거리, 위반 0.
- **모순**: 안정/후보 표면과 어긋나는 강한 관측은 모순 후보로 쌓고, 서로 독립인 관측 3개가 같은 오프셋에 모이면 그 패치만 새 위치로 옮기고 후보로 되돌려 다시 검증한다(ID 유지). 약한 표본은 증거가 아니다.
- **삭제**: 보이지 않거나 가려졌다는 이유로 지우지 않는다. 임시 표면은 독립 증거 없이 12 키프레임이 지나면 만료. 자유 공간 위반(강한 깊이가 패치보다 분명히 뒤)은 서로 다른 키프레임에서 쌓여야 하고 후보/안정은 삭제가 아니라 한 단계 강등.
- **geometryRevision**: 위치·법선이 의미 있게 바뀔 때 증가하고 변경 위치가 기록된다. 렌더러의 source 깊이 캐시는 변경 위치가 그 source 시야에 들어올 때만 다시 만든다.
- 3.0(19)의 결함을 가져오지 않았다: 가우시안당 중복 갱신, 강/약 표본의 임의 혼합, bestRange 갱신 순서(이제 판정이 불확실성 기반이라 의존하지 않음), 같은 참조 재사용을 독립으로 센 것.

## 외관

- 키프레임은 960×720 JPEG로 보관하고(메모리에는 최근 6장만 풀어 둠), 렌더러가 활성 source 4장만 GPU 텍스처로 올린다(LRU 18장 상한).
- 화소마다: source 투영 → 화면 밖/뒷면/기울기(cos < 0.15) 거절 → **source 카메라에서 본 지도 깊이와 비교해 가림 거절** → 각도·해상도 가중 → 색이 일치하면 블렌딩, 아니면 가장 좋은 한 장.
- 읽을 source가 없으면 패치의 대체 평균 색(옵션으로 분홍색 표시). 카메라 영상 배경은 명시적 비교 옵션이며 품질 평가에 쓰지 않는다.
- 노출: 같은 표면의 기준 밝기(처음 3번 관측으로 고정)와 비교해 키프레임 gain 추정(0.6~1.6). ISO를 얻을 수 없어 노출 메타데이터는 기록만 한다.

## 파일 형식

- `.kmospace`: `KMOS` 컨테이너(manifest.json, surfaces.bin, cameras.json, tex/NNNNNN.jpg). 읽을 때 필요한 덩어리만 읽는다.
- `.ply`/`.state`: 비교·호환용 평면 가우시안(SH0)과 패치 상태(PLY 체크섬으로 연결). V2의 원본 텍스처 품질은 담지 않는다.
- `.meta.json`: runId, 로그 파일, 개수. `.summary.txt`: 요약. `<runId>.jsonl`(experiment-logs): 키프레임별 통계(`sv2_kf`)·1초 요약(`sv2_hb`)·표시 지연(`sv2_display`).
- `.kmoreplay`(연구 기록 옵션): 파이프라인 입력(960폭 JPEG q0.9 + 포즈·K·시각·방향·추적·노출). 자동 업로드 없음, 600장·400MB 상한.
- 테스트_02의 JSONL에는 RGB가 없어 그 실행은 재생할 수 없다. V2는 연구 기록을 켠 실행부터 재생할 수 있다.

## 로그(측정 정의)

- `toMap`: 캡처 시각 → 지도 반영 완료. `toPublish`: 캡처 → 렌더용 스냅샷 게시(0.25초 간격 영향). `toDisplay`: 캡처 → **drawable presentedTime**(실제 표시). SDK가 presentedTime 선언을 주지 않아 런타임에 getter가 있을 때만 KVC로 읽고, 읽지 못하면 GPU 완료 시각으로 근사한다. 로그에 시각 출처(`present`/`gpuEnd`)를 함께 남기므로 두 값을 섞어 해석하지 않는다.
- 처음 도달 시각: 첫 입력, 첫 유효 시차(깊이 표본 존재), 첫 표면, 첫 표시.
- 렌더러 GPU 계수(화소 1/16 표본): 질감 지원 / source 없음 / 가림으로 전부 거절 / 색 불일치 선택. 텍스처 상주 수·바이트, 가림 캐시 재생성 횟수.
- 30fps 표시는 생성 속도·화질 지표가 아니다. 지연 p95 250ms, coverage·PSNR 목표는 **목표**이며 달성값이 아니다.

## 검증 범위

- 자동(CI, 시뮬레이터): 좌표·K·방향·유니폼 투영, 합성 장면 깊이·역방향 일치, 경계/얇은 구조 표본, 독립 증거·상태 전이·모순·자유 공간·만료·상한, 공간 인덱스, 저장·다시 열기(같은 장면 비트 동일)·공유 묶음·재생 결정성, CPU 기준 렌더(전경 가림·배경 색 누출·held-out 전체 화소/지원 면적), 합성 전체 경로 held-out.
- Metal 장치가 있으면 GPU 오프스크린과 CPU 기준 렌더를 비교한다(없으면 건너뜀 → 미측정).
- **미측정**: A15 실기기 속도·열, 실제 Metal 렌더 성능, 실사 화질(PSNR/SSIM), 실제 거리 정확도, ARKit 포즈 오차 영향, 5분 이상 연속 실행.

## 한계(알려진 것)

- 포즈는 ARKit 값을 그대로 믿는다(BA 없음). 포즈 드리프트·재위치 오류가 형상에 들어간다.
- 패치 크기는 생성 시점의 표본 간격으로 고정된다. 재관측은 위치·법선·불확실성과 텍스처를 개선하지만 세분화하지 않는다.
- 세그먼트(추적 복구·일시정지 재개)는 좌표를 검증하지 않고 서로 병합하지 않는다.
- 저텍스처는 검증된 평면 안에서만 채운다. 평면이 아닌 큰 무늬 없는 면은 구멍으로 남는다.
- ARPlaneAnchor는 쓰지 않는다.
